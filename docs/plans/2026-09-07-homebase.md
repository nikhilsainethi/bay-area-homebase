# Bay Area Homebase Implementation Plan

**Goal:** Build the user-approved map-first apartment search and persistent tracker; publish privately and push source to the user's GitHub.

**Architecture:** Vinext React app with Leaflet map, user-triggered Overpass apartment discovery, D1 records scoped to authenticated Sites identity, and external Google Maps directions to 100 W Caribbean Dr. No scraped inventory, fabricated vacancies, or browser-only authoritative storage. Private GitHub repo is the default for personal source.

**Tech Stack:** Vinext/Vite, React, TypeScript, Shadcn, Leaflet, D1/Drizzle migrations, Cloudflare Worker.

1. Create minimal map workspace in app/page.tsx, app/homebase.tsx, and app/globals.css. Theme: warm ivory, forest-green controls, blue discovery pins, persistent map/list split. Preview once compiled.
2. Test lib/domain.ts validation, search normalization, costs, and commute links with node:test. Watch failures then implement. Add property and floor-plan types supporting optional prices, bathroom fractions, dimensions and availability. Do not conflate unknown rent with zero.
3. Add db/schema.ts and prepared queries through db/store.ts. Generate migration; test CRUD, user isolation, and validation through HTTP against local D1. Production identity never falls back to anonymous writes.
4. Add bounded, cached Overpass discovery endpoint, server-side bbox validation, explicit search button, safe external website links. Allow manual map placement where OSM coverage is incomplete. No public Nominatim integration.
5. Implement editor, multiple units, contact details, filters, status and favorites, tracker table, deletion confirmation, and office directions. Show straight-line distance explicitly, with optional manually researched drive minutes and miles.
6. Add WebMCP read/search/save surface. Check TypeScript, tests, HTTP flows, and production build. Review source, then commit and push identical source to Sites and a new private GitHub repository. Publish owner-only and verify terminal deployment state.

## Accepted design

Map on one side, property results/shortlist beside it, five city shortcuts. Clicking a pin opens property details with website and search links and Save to tracker. Saved properties carry editable contact, pricing, layout, size, home type, dates, progress and notes; each property supports multiple floor plans. Office destination supplied by user: Google SVL-CRBN100, 100 W Caribbean Dr, Sunnyvale CA 94089.

## Final user-approved hosting change
The user requested GitHub Pages and explicitly chose browser-local storage with export/import backups. The shipped Pages build uses `lib/browser-store.ts` and direct bounded Overpass requests, with optional Google Maps configured in the app. GitHub plan rejected Pages for the empty private repo, so the repository was made public for the requested deployment; personal apartment records never enter Git. The earlier Sites runtime remains an optional source path and was not published.
